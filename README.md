# 🚗 Tkinter Car Racing Game

A simple and fun Car Racing Game developed using Python and Tkinter GUI.  
The player controls a car and avoids enemy cars while trying to achieve the highest score possible.

---

# 📌 Features

- 🎮 Smooth car movement
- 🚘 Enemy cars generation
- 💥 Collision detection
- 🏆 High score saving system
- 📈 Score tracking
- 🖥️ Simple Tkinter GUI
- ⚡ Easy keyboard controls

---

# 🛠️ Technologies Used

- Python
- Tkinter
- File Handling

# 📊 Game Features Explained

## 🚘 Player Car
The player controls a car that can move left and right on the road.

## 🚗 Enemy Cars
Enemy cars continuously move downward from random positions.

## 💥 Collision Detection
If the player car collides with an enemy car, the game ends.

## 🏆 High Score System
The highest score is automatically saved in `game_results.txt`.
